Ofrenda

Build a small remembrance page for someone you miss, using your own words and photos. It runs on your own computer, and nothing is uploaded.

1. Who are you remembering?

Only the name is required. Everything else is optional and stays on this computer.

2. Memories

Write a few things you remember, in your own words. The remembrance will only use what you write here, so short and true is better than long and polished.

3. Photos (optional)

Up to 4 photos. If you add a caption, the remembrance uses your words. If you leave it blank, the local model will describe only what is visible in the photo, and you can edit it before saving.

4. Ready?

Add a name and at least one memory or photo to continue.
